Hello Web Service

GET /hello/{name} → Hello "name"

The name is a path parameter — part of the URL itself, not a ?query=string. Leave it out and it defaults to World.

RequestResponse
/hello/WorldHello "World"
/hello/JoséHello "José"
/hello/Hello "World" — defaulted
/helloHello "World" — defaulted
/hello/a/bHello "a" — first segment

From a terminal:

curl http://localhost:8080/hello/World
